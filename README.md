# TharunRongalaPortfolio

A modern, responsive portfolio website showcasing Tharun Rongala's AI engineering projects, skills, and achievements.

## Features

- **Modern UI Design**: Clean, minimalist interface with gradient effects and smooth animations
- **Responsive**: Mobile-first design that works on all devices
- **Dark Theme**: Eye-friendly dark color scheme optimized for readability
- **Interactive Elements**: Typewriter effect, smooth scroll navigation, copy-to-clipboard functionality
- **Project Showcase**: Detailed project cards with tech stacks and descriptions
- **Skills Grid**: Organized technical skills by category

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript
- Phosphor Icons
- Google Fonts (Inter)

## Sections

1. **Navigation Bar**: Fixed navbar with smooth navigation
2. **Hero Section**: Introduction with code window animation
3. **About**: Bio, achievements, and quick facts
4. **Skills**: Categorized technical skills
5. **Projects**: Featured project showcases
6. **Contact**: Email and social media links
7. **Footer**: Copyright information

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. Customize the content with your information

## Customization

- **Colors**: Update CSS variables in `style.css` (--primary-color, --secondary-color, etc.)
- **Content**: Edit text content in `index.html`
- **Projects**: Add/remove project cards in the projects section
- **Social Links**: Update social media URLs in the contact section

## Deployment

This portfolio can be hosted on GitHub Pages:

1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Set source to `main` branch
4. Your site will be live at `https://yourusername.github.io/TharunRongalaPortfolio`
